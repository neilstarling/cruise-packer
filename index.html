Using the Cruise Packing App

Plan outfits for each cruise, keep track of your wardrobe, and print a packing list organized by suitcase.

1. Build your wardrobes

Open Settings and use Add Clothing Item to add an item by name and category. Select one or more colour labels to show on the item, then choose Add Tile. Items appear under their category in The Wardrobes.

Her wardrobe includes dresses, jackets, shoes, handbags, and walking sticks. His wardrobe includes jackets, waistcoats, shirts, trousers, and shoes. In the wardrobe, use the Her/Him buttons to switch wardrobes. Use Filter colours on a category to show items with selected labels. Each tile has a delete button.

2. Add and manage cruises

Open Cruises and choose Add a new Cruise to create a cruise and open its planner. Enter departure and return dates, destinations, ship, and duration. Cruise details and plans save automatically in this browser.

The Cruises page lists future cruises by nearest departure first and completed cruises by most recent return first. Each row shows dates, duration, ship, and destinations. Choose View to open a cruise's planner, or Delete Cruise and confirm to remove it.

3. Plan nightly outfits

In a cruise planner, select a clothing slot in either person's row and choose a wardrobe item. Choose a suitcase for each person's outfit. Select Formal or Gala for each night's dress code. Use Copy Outfit beside a night to copy the selected items for both people to the first completely empty night of another future cruise.

Drag a night by its ↕ handle to reorder the planner. You can also focus the handle and press the up or down arrow keys. The outfits, dress codes, and suitcase assignments move with the night.

4. Print a packing list

Choose Print Packing List / Save as PDF in a cruise planner. The print view groups each night’s outfits by suitcase and includes any outfits that have not been assigned to a suitcase. Use your browser’s print dialog to print or save as PDF.

5. Customize Settings and backups

In Settings, rename the default suitcases, or use Add Suitcase to create more named suitcases. All suitcases can be assigned to outfits and appear in packing lists. Add cruise ships to the ship choices, and create custom sticker labels by setting a name, background colour, and tag colour. Active labels can be deleted.

Use Export File to download a backup of wardrobes, labels, suitcase names, ships, and all cruise plans. Import File replaces the current app data after confirmation; export a backup first if you may want to keep the existing data.

Data and privacy

App data is stored in this browser on this device. It is not automatically synchronized to other devices. Browser storage can be cleared by the browser or device, so export backups regularly if you want to preserve your plans.
